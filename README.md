# AI-ML-Internship-Task1-Linear-Regression
# 🏠 California Housing Price Prediction (Machine Learning Internship Task)

## 📌 Project Overview

This project is part of my AI & Machine Learning Internship.

The objective of this task is to implement a Linear Regression model to predict house prices using the California Housing dataset.

The project demonstrates the complete machine learning workflow including:

- Data Loading
- Exploratory Data Analysis (EDA)
- Data Preprocessing
- Train-Test Split
- Model Training
- Model Evaluation
- Data Visualization

---

## 📊 Dataset Used

California Housing Dataset (Available in sklearn)

Target Variable:
- Median House Value

Features Include:
- Median Income
- House Age
- Average Rooms
- Population
- Latitude
- Longitude
- And other housing-related attributes

---

## 🛠️ Technologies & Libraries Used

- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

---

## 🤖 Machine Learning Model

Model Used:
- Linear Regression

Why Linear Regression?
- Simple and interpretable
- Suitable for continuous value prediction
- Good baseline model for regression problems

---

## 📈 Model Evaluation Metrics

The model was evaluated using:

- MAE (Mean Absolute Error)
- RMSE (Root Mean Squared Error)
- R² Score

### Results:

- MAE: 0.5332
- RMSE: 0.7455
- R² Score: 0.5757

The model explains approximately 57% of the variance in the dataset.

---

## 📊 Visualization

A scatter plot was created to compare:

- Actual House Prices
- Predicted House Prices

The plot shows a positive linear relationship indicating reasonable model performance.
